# OBS Studio quickstart

OBS Studio: https://obsproject.com/ — free, open-source recording and streaming.

- Scenes live in `~/.config/obs-studio/` (JSON, portable).
- Headless recording: `obs --startrecording --minimize-to-tray`.
- Useful plugins: obs-websocket (automation), obs-backgroundremoval.
- Keep scene collections in git; they are plain JSON.
